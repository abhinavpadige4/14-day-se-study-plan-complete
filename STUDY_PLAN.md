# 14-Day Software Engineering Study Plan

## Day 1-2: Arrays, Strings, Hashing (3-4 hours/day)

### Day 1: Arrays & Strings Fundamentals
**⏰ Time: 3.5 hours**
- **Theory (30 min)**: Array and string basics, time/space complexity analysis
- **Coding Problems (2 hours)**:
  1. [Two Sum](https://leetcode.com/problems/two-sum/) - Easy
  2. [Valid Anagram](https://leetcode.com/problems/valid-anagram/) - Easy
  3. [Contains Duplicate](https://leetcode.com/problems/contains-duplicate/) - Easy
  4. [Product of Array Except Self](https://leetcode.com/problems/product-of-array-except-self/) - Medium
  5. [Maximum Subarray](https://leetcode.com/problems/maximum-subarray/) - Easy
- **MCQs (30 min)**: Array indexing, string manipulation, hash table concepts
- **Resources**:
  - [Array Interview Questions](https://www.geeksforgeeks.org/array-data-structure/)
  - [String Manipulation in Python](https://www.programiz.com/python-programming/string)
  - [Hash Table Basics](https://www.geeksforgeeks.org/hashing-data-structure/)

### Day 2: Advanced Arrays & Hashing
**⏰ Time: 3.5 hours**
- **Theory (30 min)**: Sliding window, two-pointer techniques, hash map applications
- **Coding Problems (2 hours)**:
  1. [Longest Substring Without Repeating Characters](https://leetcode.com/problems/longest-substring-without-repeating-characters/) - Medium
  2. [3Sum](https://leetcode.com/problems/3sum/) - Medium
  3. [Group Anagrams](https://leetcode.com/problems/group-anagrams/) - Medium
  4. [Top K Frequent Elements](https://leetcode.com/problems/top-k-frequent-elements/) - Medium
  5. [Encode and Decode Strings](https://leetcode.com/problems/encode-and-decode-strings/) - Medium
- **MCQs (30 min)**: Sliding window, two-pointer, frequency counting
- **Practice Tasks**: Implement hash map from scratch, solve 5 additional LeetCode easy problems

## Day 3-4: Trees & Graphs (3-4 hours/day)

### Day 3: Trees Fundamentals
**⏰ Time: 3.5 hours**
- **Theory (30 min)**: Binary tree properties, tree traversal methods (DFS/BFS)
- **Coding Problems (2 hours)**:
  1. [Maximum Depth of Binary Tree](https://leetcode.com/problems/maximum-depth-of-binary-tree/) - Easy
  2. [Binary Tree Inorder Traversal](https://leetcode.com/problems/binary-tree-inorder-traversal/) - Easy
  3. [Validate Binary Search Tree](https://leetcode.com/problems/validate-binary-search-tree/) - Medium
  4. [Binary Tree Level Order Traversal](https://leetcode.com/problems/binary-tree-level-order-traversal/) - Medium
  5. [Convert Sorted Array to Binary Search Tree](https://leetcode.com/problems/convert-sorted-array-to-binary-search-tree/) - Easy
- **MCQs (30 min)**: Tree traversal, BST properties, recursion vs iteration

**⏰ Time: 3.5 hours**

- **Coding Problems (2 hours)**:
  1. [Number of Islands](https://leetcode.com/problems/number-of-islands/) - Medium
  2. [Clone Graph](https://leetcode.com/problems/clone-graph/) - Medium
  3. [Course Schedule](https://leetcode.com/problems/course-schedule/) - Medium

  5. [Binary Tree Right Side View](https://leetcode.com/problems/binary-tree-right-side-view/) - Medium
- **MCQs (30 min)**: Graph traversal, adjacency list/matrix, topological sort
- **Practice Tasks**: Implement graph from adjacency list, solve tree diameter problem

## Day 5-6: Dynamic Programming (3-4 hours/day)

### Day 5: DP Fundamentals
**⏰ Time: 3.5 hours**
- **Theory (30 min)**: DP principles, memoization vs tabulation, state definition
- **Coding Problems (2 hours)**:
  1. [Climbing Stairs](https://leetcode.com/problems/climbing-stairs/) - Easy
  2. [Best Time to Buy and Sell Stock](https://leetcode.com/problems/best-time-to-buy-and-sell-stock/) - Easy
  3. [Maximum Subarray](https://leetcode.com/problems/maximum-subarray/) - Easy (Kadane's algorithm)
  4. [House Robber](https://leetcode.com/problems/house-robber/) - Medium
  5. [Unique Paths](https://leetcode.com/problems/unique-paths/) - Medium
- **MCQs (30 min)**: Optimal substructure, overlapping subproblems, DP vs recursion
- **Resources**:
  - [Dynamic Programming Introduction](https://www.geeksforgeeks.org/dynamic-programming/)
  - [DP Patterns Guide](https://leetcode.com/discuss/general-discussion/458695/dynamic-programming-patterns)
  - [Memoization vs Tabulation](https://www.geeksforgeeks.org/tabulation-vs-memoization/)

### Day 6: Advanced DP
**⏰ Time: 3.5 hours**
- **Theory (30 min)**: 2D DP, string DP, interval DP
- **Coding Problems (2 hours)**:
  1. [Longest Increasing Subsequence](https://leetcode.com/problems/longest-increasing-subsequence/) - Medium
  2. [Longest Common Subsequence](https://leetcode.com/problems/longest-common-subsequence/) - Medium
  3. [Edit Distance](https://leetcode.com/problems/edit-distance/) - Medium
  4. [Word Break](https://leetcode.com/problems/word-break/) - Medium
  5. [Coin Change](https://leetcode.com/problems/coin-change/) - Medium
- **MCQs (30 min)**: State transition, base cases, space optimization
- **Practice Tasks**: Solve 5 DP variations, implement space-optimized versions

## Day 14: Mock Interviews & Behavioral Prep (3-4 hours)

**⏰ Time: 3.5 hours**
- **Mock Technical Interview (1.5 hours)**:
  - Solve 3 LeetCode medium problems under time pressure
  - Practice explaining thought process aloud
  - Focus on arrays/strings, trees, and DP problems
- **System Design Mock Interview (45 min)**:
  - Design URL shortener or chat system on whiteboard
  - Discuss trade-offs and scalability considerations
- **Behavioral Interview Prep (1 hour)**:

- **Final Review (30 min)**:

  - Create personalized study plan for continued learning
  - Celebrate completion! 🎉

## Daily Structure Summary
Each day follows this pattern:
- **Theory**: 30-45 minutes of concept learning
- **Hands-on Practice**: 2 hours of coding/problems
- **MCQs**: 30 minutes of concept reinforcement
- **Mock Interview/Review**: 30-45 minutes of interview prep or system design

**Total Daily Time**: 3.5 hours (adjustable based on your schedule)
